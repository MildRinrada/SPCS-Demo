# เดโม: ระบบเทียบราคาซัพพลายเออร์ + ใบเสนอราคา

repo นี้มีแต่ไฟล์เว็บเดโมที่บิลด์แล้ว Vercel นำ `public/` ขึ้นเว็บตรงๆ โดยไม่ต้องบิลด์ ข้อมูลตัวอย่างและการคำนวณทั้งหมดทำงานในเบราว์เซอร์ของผู้เข้าชม ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูล

- `public/` คือเว็บทั้งหมด (HTML, CSS และ JS)
- `vercel.json` ตั้งโฟลเดอร์ที่เสิร์ฟ เปิด `cleanUrls` ให้ `/quotes` เปิดไฟล์ `quotes.html` ได้ และตั้ง header ของเว็บ

ไฟล์ทั้งหมดในนี้ถูกเขียนทับทุกครั้งที่อัปเดตเดโม อย่าแก้ไฟล์ที่นี่ ให้แก้ใน repo หลักของระบบ แล้วรัน `npm run deploy:demo` ในโฟลเดอร์ `web`
